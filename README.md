## Stream

Inter site communications between two or more sites

**Steps to Connect two sites**
1. Create same user on both site
2. Generate API Key and API Secret for new user in both site
3. Go to Gov site and create record of Event Producer GC and put data of Real site (site url, user, api key and secret)
4. Add documents in child table and set Conditions if required
5. Go to Real site, open Event Consumer GC and Change the Approval status line wise
